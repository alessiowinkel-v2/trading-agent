Daily pre-market research entries are appended here. Each routine reads the tail before any trade.

## Format for each entry

```

### Account snapshot
- Equity: $X
- Cash: $X
- Buying power: $X
- Daytrade count: N/3 (rolling 5-day)
- Open positions: N

### Market context
- WTI / Brent:
- S&P 500 futures:
- VIX:
- Today's catalysts:
- Earnings before open:
- Economic calendar:
- Sector momentum:

### Currently-held positions check
For each open position:
- TICKER: any material news, thesis still intact?

### Trade ideas (0-3 candidates)
1. TICKER — catalyst, entry $X, stop $X, target $X, R:R X:1
   Thesis: ...
2. ...

### Risk factors for today
- ...

### Decision
TRADE (with which ideas) or HOLD (default — patience > activity)
```
